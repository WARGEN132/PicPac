# PicPac — Фотокниги и фотопечать со смартфона
**ООО «Фотопринт» • ТЗ Версия 1.0 MVP**

Мобильное PWA-приложение для создания фотокниг с помощью искусственного интеллекта и быстрого заказа фотопечати со смартфона.

## 🚀 Реализованный сквозной путь (Разделы 1–28 ТЗ)

1. **Главная (Раздел 6):**
   - Крупное главное действие **«Создать фотокнигу»** с AI-генератором.
   - Второе действие **«Напечатать фотографии»** (прямой сценарий без AI).
   - Блок активных проектов с возможностью мгновенно продолжить редактирование.
   - Популярные форматы (Classic, Lite, Premium, химическая печать).

2. **Каталог (Раздел 7):**
   - Фотокниги Classic (Хит продаж, Layflat 180°, от 49.00 BYN).
   - Фотокниги Lite (Журнальный формат, от 29.00 BYN).
   - Фотокниги Premium (Итальянская экокожа, тиснение, от 79.00 BYN).
   - Фотохимическая фотопечать (Fujifilm Crystal Archive, от 0.65 BYN).
   - Цифровая фотопечать (Плотная 300 г/м², от 0.80 BYN).

3. **Мастер создания фотокниги (Раздел 8):**
   - Шаг 1: Формат (20×20, 20×30, 30×30) и объём страниц (20, 30, 40).
   - Шаг 2: Загрузка фото со смартфона или выбор готовых тестовых фотосетов с проверкой качества и дубликатов.
   - Шаг 3: Выбор тематики (Семья, Путешествие, Свадьба, Детство), стиля и текстовых пожеланий к ИИ.
   - Шаг 4: Поэтапная визуальная генерация макета книги.

4. **AI-редактор фотокниги (Раздел 9, 10, 11):**
   - **Структурированный JSON-макет:** развороты состоят из отдельных редактируемых элементов с координатами, размерами и свойствами.
   - **Интерактивный предпросмотр разворота:** Обложка, Развороты 1-6, линии безопасных зон (Safe Zones / Bleed).
   - **Чат с ИИ и текстовые команды:** «Сделай обложку более минималистичной», «Добавь больше воздуха между фото», «Убери текст с этой страницы», «Поменяй фотографии местами», «Все страницы в тёплой пастельной гамме» с поддержкой отмены (Undo)!
   - **Ручные инструменты:** смена фона разворота, быстрые перестановки, проверка вылетов под обрез.

5. **Прямой сценарий фотопечати (Раздел 13):**
   - Выбор размера (10×15, 15×21, Polaroid), бумаги (глянцевая/матовая), количества копий для каждого кадра и моментальный расчёт в BYN.

6. **Корзина и Оформление заказа (Раздел 14, 15):**
   - Объединение фотокниг и фотопечати.
   - Промокоды (`START10`, `HACKATHON`, `PICPAC5`).
   - Доставка по Беларуси (Европочта 5.00 BYN, Белпочта 5.50 BYN, Курьер 8.50 BYN, EMS 12.00 BYN).
   - Идемпотентность оформления через `Idempotency-Key`.
   - Присвоение уникального номера заказа (`PP-2026-XXXX`).

7. **Профиль, Заказы и Панель оператора (Раздел 16, 17, 20):**
   - Переключатель роли в шапке: **Клиент** (`customer@test.by`) ⇄ **Оператор** (`operator@test.by`).
   - Статусная лента: Принят → Модерация → В производстве → Готов → Доставлен.
   - Подача обращений в поддержку по конкретному заказу.
   - В режиме оператора: смена статусов, просмотр журналов `audit_logs` и тикетов.

## ⚡ Быстрый запуск

```bash
# 1. Установка зависимостей (если ещё не установлены)
npm install

# 2. Запуск приложения в режиме разработки (Express API + Vite Dev Middleware)
npm run dev
```

При первом запуске сервер автоматически:
1. Создаст директорию `data/` и файл базы данных SQLite `data/picpac.db`.
2. Применит схему таблиц из `server/src/db/schema.sql` (с `PRAGMA foreign_keys = ON;` и `journal_mode = WAL`).
3. Запустит автоматический сидинг тестовых данных:
   - **5 продуктов** (фотокнига, печать, холст, магниты, календарь) с 15 вариантами;
   - **2 тестовых аккаунта** (клиент и оператор);
   - **222 клиента** (ФИО, телефоны РБ, адреса в Минске и областных центрах);
   - **520 синтетических заказов** со статусной историей;
   - **310 обращений в службу поддержки**.

## 🩺 Проверка работы API

После запуска команды `npm run dev`:

1. **Проверка работоспособности (Health check):**
   ```bash
   curl http://localhost:3000/api/health
   ```
   *Возвращает HTTP 200, статус 'ok', 'connected' и количество записей в базе.*

2. **Проверка каталога продуктов:**
   ```bash
   curl http://localhost:3000/api/products
   ```
   *Возвращает 5 активных продуктов с вариантами и ценами в BYN.*

3. **Интерфейс приложения:**
   Откройте в браузере: `http://localhost:3000`

4. **Запуск автоматических тестов:**
   ```bash
   npm test
   ```
   *(Запускает встроенный тест-раннер `tsx --test` для базы данных, сидов и AI-интерфейса).*

5. **Ручной перезапуск сидинга базы данных:**
   ```bash
   npm run seed
   ```
