# PicPac

PicPac — демоприложение ООО «Фотопринт» для создания фотокниг и заказа фотопечати
со смартфона. В нём можно собрать и отредактировать макет, добавить товары в
корзину, оформить тестовый заказ с доставкой по Беларуси и посмотреть его статус.

## Быстрый запуск

Установите Node.js 22.12+ (либо более новую поддерживаемую версию Node.js) и npm.
В корне репозитория выполните:

```bash
npm install --no-package-lock --legacy-peer-deps
DB_PATH=./data/local/picpac.db npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000). Express обслуживает API
и клиент Vite на одном порту. Сервер создаст отдельную SQLite-базу, применит схему
и заполнит её каталогом, тестовыми аккаунтами, заказами и обращениями. Каталог
`data/local/` используется для локальных данных и исключён из Git. Ключи внешних
сервисов для запуска не нужны.

Флаг `--legacy-peer-deps` нужен из-за расхождения между версией `esbuild` в
`package.json` и диапазоном, указанным в необязательных peer-зависимостях Vite.

Если порт занят, запустите сервер с другим портом:

```bash
PORT=3001 DB_PATH=./data/local/picpac.db npm run dev
```

## Сценарии для демонстрации

Роль в интерфейсе меняется кнопкой «Клиент» / «Оператор» в шапке.

- **Фотокнига.** В каталоге нажмите «Создать с ИИ» на карточке фотокниги,
  выберите тестовую галерею или загрузите свои фото. Создайте макет,
  отредактируйте разворот и добавьте книгу в корзину.
- **Фотопечать.** Добавьте фото, выберите формат, бумагу и количество копий.
  Перейдите в корзину, выберите доставку и оформите тестовый заказ. Цены указаны
  в BYN. Промокод `START10` даёт скидку 10% на товары.
- **Обработка заказа.** Переключитесь на роль оператора, откройте панель и измените
  статус заказа. В профиле клиента можно посмотреть историю статусов.

Генерация макета и команды редактора работают по локальным шаблонам. Онлайн-оплата,
передача заказов в производство и оформление отправлений у перевозчиков в демо
не подключены. Для отображения части демонстрационных фотографий нужен интернет.

### Известные ограничения

- При сохранении нового макета редактор показывает сообщение об успехе, но
  проект не появляется в SQLite. Сохранение отправляет запрос только у макетов
  с уже присвоенным идентификатором.
- Стоимость доставки в форме и в сохранённом заказе различается. Например,
  форма показывает 5,90 BYN за Европочту, а API записывает 5,00 BYN.

Для проверки `POST /api/auth/login` доступны учётные записи из демоданных:

| Роль | Email | Пароль |
| --- | --- | --- |
| Клиент | `customer@test.by` | `Customer123!` |
| Оператор | `operator@test.by` | `Operator123!` |

## Проверки

При запущенном сервере проверьте главную страницу, соединение с SQLite и каталог:

```bash
curl -fsS -o /dev/null http://localhost:3000/
curl -fsS http://localhost:3000/api/health
curl -fsS http://localhost:3000/api/products
```

В корне проекта выполните:

```bash
DB_PATH=./data/local/test.db npm test
npm run lint
npm run build
```

Тесты проверяют схему SQLite, демоданные и имитацию анализа фотографий.
`lint` проверяет типы TypeScript, `build` собирает клиент в `dist/`.
Чтобы посмотреть собранный клиент вместе с API, остановите dev-сервер и выполните:

```bash
NODE_ENV=production DB_PATH=./data/local/picpac.db npm start
```

## Настройки

Сервер читает переменные окружения и файл `.env` из корня проекта.

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `PORT` | `3000` | HTTP-порт приложения |
| `NODE_ENV` | Режим разработки | При `production` Express отдаёт клиент из `dist/` |
| `DB_PATH` | `./data/picpac.db` | Путь к SQLite-базе |
| `AI_PROVIDER` | `mock` | Режим анализа фото. Значения `openai` и `local` также используют заглушку |
| `DISABLE_HMR` | Не задана | Значение `true` отключает HMR и наблюдение за файлами Vite |

В репозитории лежит демобаза `data/picpac.db`. Для локальной работы используйте
отдельный `DB_PATH`, как в примерах выше. Демоверсия предназначена для локального
показа. Серверные маршруты не проверяют права клиента и оператора, поэтому не
размещайте приложение в открытом доступе с реальными данными.
